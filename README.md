# Royal Blue Hydrangea Wedding Invitation

Sample GitHub Pages invitation.

## Preview locally
Open `index.html` in a browser. For the YouTube background music, internet access is required.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Go to Settings → Pages.
4. Choose Deploy from a branch → `main` → `/ (root)` → Save.
